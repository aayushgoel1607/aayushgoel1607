## 01 / ScholarSphere

<a href="https://github.com/aayushgoel1607/-ScholarSphere">
  <img src="https://raw.githubusercontent.com/aayushgoel1607/aayushgoel1607/main/assets/scholarsphere.svg" width="100%" alt="ScholarSphere — learn through play, plan through focus" />
</a>

**Personal project · Owner: `aayushgoel1607` · Next.js / TypeScript / Supabase**

ScholarSphere is a connected learning platform with two complete ways to work: **Game Learning** turns learner-selected material into adaptive, source-aware practice; **Focus Desk** connects timers, subjects, tasks, goals, calendar planning, and analytics. Both modes feed one progression system for credits, streaks, rewards, ranks, history, and personal bests.

<table>
<tr>
<td width="50%" valign="top">

#### 🎮 Game Learning

- PDF, DOCX, PPTX, TXT and Wikipedia sources
- Five pixel-inspired learning games
- Adaptive levels, lives, streaks and feedback
- Source labels and validated question flow

</td>
<td width="50%" valign="top">

#### ⏱️ Focus Desk

- Persistent Pomodoro and custom sessions
- Quest board, subjects and calendar planning
- Daily goals, history and study analytics
- Cross-device Supabase-backed progress

</td>
</tr>
</table>

**Engineering depth:** authentication, storage, row-level security, protected reward functions, adaptive-selection rules, persistent timers, test coverage, and a production deployment that keeps both modes synchronized.

## 02 / NodeFlow

<a href="https://github.com/PREMBISOY/nodeflow">
  <img src="https://raw.githubusercontent.com/aayushgoel1607/aayushgoel1607/main/assets/nodeflow-card.svg" width="100%" alt="NodeFlow — shared project intelligence for humans and AI agents" />
</a>

**Team project · Repository owner: `PREMBISOY` · Full-stack / platform contributor**

NodeFlow is a model-agnostic project-intelligence layer for teams of humans and AI agents. Git remains the source of truth for code; NodeFlow structures architecture, decisions, work, changes, dependencies, and agent activity so tools can retrieve the context that matters.

**My documented contribution:** I worked across the platform rather than a single screen—building project-knowledge persistence and a SQLAlchemy repository adapter; authenticated team foundations and team-scoped APIs; centralized RBAC, global RLS and tenant validation; repository connections, GitHub OAuth and webhook idempotency; hardened migration/deployment paths; isolated test fixtures; and light-mode frontend contrast fixes.

```text
platform       authenticated teams · scoped project APIs · RBAC
persistence    SQLAlchemy adapters · knowledge storage · request sessions
security       RLS · tenant isolation · OAuth and webhook hardening
reliability    migrations · idempotency · integration tests · documentation
```

## 03 / FinSight-AI

<a href="https://github.com/PREMBISOY/FinSight-AI">
  <img src="https://raw.githubusercontent.com/aayushgoel1607/aayushgoel1607/main/assets/finsight-card.svg" width="100%" alt="FinSight-AI — explainable multi-agent financial intelligence" />
</a>

**Hackathon team project · Repository owner: `PREMBISOY` · AI and frontend contributor**

FinSight-AI is an explainable, evidence-backed multi-agent financial-intelligence prototype. Technical, fundamental, and sentiment agents inspect different evidence in parallel; deterministic synthesis and risk layers combine the findings for an investor profile, while grounded AI adds current context without overriding the computed result.

**My documented contribution:** I implemented the **fundamental RAG agent** with sentence-transformer retrieval and an expanded document corpus. I also improved the frontend’s local-profile flow, login behavior, theme-safe market symbols, analysis messaging, AI fallback explanation, profile naming, and deployment readiness.

```text
intelligence   fundamental RAG · embedding retrieval · cited corpus
experience     profile flow · login state · theme-safe market UI
clarity        AI fallback messaging · investor context · analysis flow
delivery       merge integration · deployment fixes · Railway rebuilds
```
